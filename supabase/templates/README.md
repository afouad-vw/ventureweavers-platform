# Auth email templates

Paste each file into Supabase → Authentication → Emails (needs custom SMTP through Resend).

| Template | Subject | File |
| --- | --- | --- |
| Confirm sign up | Confirm your VentureWeavers account | `confirm-sign-up.html` |
| Reset password | Reset your VentureWeavers password | `reset-password.html` |
| Change email address | Confirm your new email | `change-email-address.html` |
| Invite user | Your VentureWeavers admin invite | `invite-user.html` |
